# Ocean Desktop update feed

Production feeds: `https://update.oceanharness.com/dsh-desk/feeds/<target>/<channel>.yml`
with `target` = `mac-arm64` and `channel` = `stable` or `nightly`.
Qualification feeds: `https://update.oceanharness.com/dsh-desk/<32-hex-release-id>/feeds/<target>/<channel>.yml`.
Manifest binaries point at GitHub Release assets of `Ryltsevmg/Ocean`;
this repository stores only manifest bytes.
